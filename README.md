# Aviação Sem Limites — Animation Studio

Estúdio inicial de animação vetorial 2D, pensado para ser desenvolvido pelo navegador no Android.

## Configuração
- React + TypeScript
- Remotion
- Composição vertical 1080 × 1920
- 30 quadros por segundo
- Demonstração inicial de 10 segundos

## Abrir no GitHub Codespaces
1. Abra este repositório no GitHub.
2. Toque em **Code** → **Codespaces** → **Create codespace on main**.
3. No terminal do Codespaces, execute:
   `npm install`
4. Para abrir a prévia:
   `npm run dev`
5. Para renderizar MP4:
   `npm run build`
